# pBot

**A Geometry Dash macro recording and playback tool.**

pBot allows players to record their inputs, save them as reusable macros, edit existing recordings, and play them back.

## Features

- **Record:** Capture player inputs.
- **Save:** Export macros as `.gdr1` or `.gdr2` files.
- **Load:** Import previously saved macros.
- **Edit:** Modify recorded inputs.
- **Play:** Replay recorded macros.

## File formats

- `.gdr1` – Legacy macro format.
- `.gdr2` – Default and newer macro format.

## Purpose

pBot is designed for showcasing, demonstrations, and macro experimentation.
